# История изменений проекта

## 2026-02-19 — Генерация файла данных на лету

### Изменения в логике работы
- **Раньше:** Данные записывались на LittleFS (`/0.txt`) каждые 5 секунд
- **Теперь:** Файл генерируется динамически при запросе `/downfile`, запись на флеш удалена

### Технические изменения
- Удалены функции: `batchWriteToFile()`, `updateTextFileAsync()`, `create_backup()`
- Добавлен обработчик: `handleDownload()` — генерирует CSV при запросе
- Удалены переменные: `need_update`, `lastFileUpdate`, `writeBuffer`, `fname`
- Данные хранятся только в RAM (кольцевой буфер `CircularBuffer`)
